# 🔮 Astro Site v2.0.0 — JPL Edition

Первый полноценный релиз профессионального астрологического веб-приложения, работающего полностью в браузере без бэкенда. Все вычисления — на Swiss Ephemeris (WASM) с точностью NASA JPL DE441.

**🌐 Демо:** https://astro.sotis.org/
**📦 Зеркало:** https://capitalov.github.io/astro/

---

## ✨ 12 методов расчёта

| Метод | Описание |
|---|---|
| **Натальная карта** | Базовая карта с интерпретацией по системе Вронского |
| **Транзиты** | Наложение текущих планет на натальную карту (би-колесо) |
| **Соляр** | Точный момент возвращения Солнца в натальную долготу |
| **Синастрия** | Би-колесо двух карт с аспектами совместимости |
| **Прогрессии** | Вторичные прогрессии (1 день = 1 год) |
| **Композит** | Средняя карта пары (метод средней точки) |
| **Дирекции** | Символические дирекции (1° = 1 год) |
| **Хорар** | Правила Уильяма Лилли: кверент + квезит |
| **Транзиты месяца** | Список значимых транзитов на 30 дней вперёд |
| **Профекции** | Древняя техника: год жизни = один дом |
| **Фирдарии** | Персидская система планетных периодов |
| **Карта Дэвисона** | Средняя точка времени и места рождения пары |

## 🪐 Точность и настройки

- **Swiss Ephemeris (JPL DE441)** — загружаются файлы `sepl_18.se1` и `semo_18.se1`
- **6 систем домов**: Плацидус, Кох, Целые знаки, Региомонтан, Кампанус, Равные
- **2 зодиака**: Тропический и Сидерический (Лахири)
- **Часовые пояса**: Полная база IANA tzdb через `moment-timezone` с исторической точностью
- **Автогеокодинг**: База из 150 000 городов + `tz-lookup` для определения пояса по координатам

## 🤖 ИИ-интеграция

- Кнопка **«🤖 ИИ-разбор»** формирует детальный промпт с координатами всех планет, домов и аспектов
- Копирует в буфер обмена и открывает ChatGPT
- Модальное окно с предпросмотром и возможностью скопировать ещё раз
- Работает без серверной части и API-ключей (полностью безопасно)

## 📅 Дополнительные функции

- **«На сегодня»** — персональный гороскоп на текущую дату на основе транзитов
- **Экспорт в PDF** с полной поддержкой кириллицы (шрифт Roboto)
- **Скачивание SVG** — векторная карта высокого качества
- **Экспорт/импорт JSON** — сохранение и перенос карт между устройствами
- **История последних 10 карт** в `localStorage`
- **Шаринг ссылкой** с параметрами расчёта

## 🎨 Дизайн

- **iOS-стиль**: системный шрифт SF Pro, скруглённые карточки, segmented control, safe-area для «чёлки»
- **Светлая и тёмная темы** с переключателем
- **Кастомный акцентный цвет** (color picker в шапке)
- **Полная адаптивность**: от iPhone SE до 4K-мониторов
- **Sticky-кнопка «Рассчитать»** на мобильных

## 🛠 Технологии

- **Swiss Ephemeris (WASM)** через `swisseph-wasm`
- **AstroChart** для SVG-визуализации
- **Moment.js + Moment Timezone** для работы с датами и поясами
- **jsPDF + svg2pdf.js** для экспорта в PDF
- **Nominatim / cities.json** для геокодинга
- Ноль зависимостей от бэкенда
