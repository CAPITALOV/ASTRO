Полнофункциональное веб-приложение для профессиональных астрологических расчётов с точностью NASA JPL. Работает **полностью в браузере** — без сервера, без регистрации, без установки. Все вычисления выполняются на устройстве пользователя через WebAssembly.

**🌐 Демо:** https://astro.sotis.org/
**📦 GitHub Pages:** https://capitalov.github.io/ASTRO/
**📢 Релизы:** https://github.com/CAPITALOV/ASTRO/releases

### 🌍 Астрокатрография

Интерактивная карта мира (MapLibre GL) с линиями:
- **MC** (зенит) и **IC** (надир) — вертикальные меридианы
- **ASC** (восход) и **DSC** (закат) — кривые, зависящие от широты

Цвет линии соответствует планете. Показывает, где в мире планеты находились в ключевых точках в момент рождения.

### 📅 Календари

**Ретро-календарь** — таблица на год вперёд:
- 8 планет: Меркурий, Венера, Марс, Юпитер, Сатурн, Уран, Нептун, Плутон
- Точные даты начала и окончания каждого ретро-периода
- Текущий период выделен оранжевым и 🔴

**Лунный календарь** — 30 дней вперёд:
- 8 фаз (🌑🌒🌓🌔🌕🌖🌗🌘)
- Знак Луны на каждый день
- Рекомендация по сфере активности

### 🎨 Live-индикаторы неба

В шапке сайта всегда видны два бейджа:
- **☿ Меркурий** — зелёный (директный) / оранжевый (ретро)
- **🌙 Луна** — зелёный (в движении) / красный (без курса)

Автообновление каждый час. Рассчитывается на текущий момент.

### 🤖 ИИ-интеграция

Кнопка **«🤖 ИИ-разбор»** формирует структурированный промпт с полными данными карты (планеты, дома, аспекты) и открывает модальное окно:
- Промпт копируется в буфер обмена
- Кнопка «Открыть ChatGPT» — переход в новую вкладку
- Кнопка «Копировать ещё раз» — на случай, если буфер перезаписался

Работает без API-ключей и серверной части — пользователь сам решает, какому ИИ доверить интерпретацию.

### 📤 Экспорт

- **SVG** — векторная карта (AstroChart)
- **PDF** — с поддержкой кириллицы (Roboto)
- **JSON** — сохранение и импорт карт между устройствами

### 📱 PWA — установка на iPhone/Android

- `manifest.json` с иконкой и названием
- `sw.js` — офлайн-режим через Service Worker
- Установка: Safari → «Поделиться» → «На экран Домой»
- Полноэкранный режим без адресной строки

### 🎓 Интерактивный туториал

8 шагов с автозапуском при первом визите. Кнопка **«?»** в шапке для повторного запуска. Работает на Intro.js, полностью в стиле сайта.

## 🪐 Точность и настройки

- **Swiss Ephemeris JPL DE441** — эфемериды NASA (файлы `sepl_18.se1`, `semo_18.se1`)
- **Fallback на Moshier** — если файлы `.se1` недоступны
- **6 систем домов**: Плацидус, Кох, Целые знаки, Региомонтан, Кампанус, Равные
- **2 зодиака**: Тропический и Сидерический (Лахири)
- **Полная база IANA tzdb** через `moment-timezone` — историческая точность часовых поясов
- **Автогеокодинг** 150 000 городов через `cities.json` + `tz-lookup`

## 🛠 Технологический стек

| Слой | Технология |
|---|---|
| **Расчёты** | `swisseph-wasm` (Swiss Ephemeris в WASM) |
| **Натальные карты** | `@astrodraw/astrochart` (SVG) |
| **Карта мира** | `maplibre-gl` (векторные тайлы) |
| **Время** | `moment.js`, `moment-timezone` |
| **Часовые пояса** | `tz-lookup` |
| **PDF** | `jsPDF` + `svg2pdf.js` |
| **Туториал** | `intro.js` |
| **Геокодинг** | `cities.json` + Nominatim-стиль |
| **PWA** | Service Worker + Manifest |

**Ноль зависимостей от бэкенда.** Всё работает на клиенте.
