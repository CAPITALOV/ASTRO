# 🔮 Астрология — карты, хорар, транзиты

Статический веб-сайт для профессионального расчёта астрологических карт. Работает полностью в браузере без бэкенда.

**Боевой сайт:** [astro.sotis.org](https://astro.sotis.org/)
**Зеркало (GitHub Pages):** [capitalov.github.io/astro](https://capitalov.github.io/astro/)

## ✨ Возможности

- **9 режимов расчёта:**
  - **Натальная карта** с интерпретацией по системе С.А. Вронского.
  - **Транзиты** на любую дату (би-колесо).
  - **Соляр** — точный момент возвращения Солнца в натальную долготу.
  - **Синастрия** — наложение двух карт.
  - **Прогрессии** (вторичные: 1 день = 1 год).
  - **Композит** — средняя карта пары.
  - **Символические дирекции** (1° = 1 год).
  - **Хорар** — по правилам Уильяма Лилли (кверент + квезит).
  - **Транзиты на месяц** — список значимых событий на 30 дней.
- **Точность:** Swiss Ephemeris (встроенная эфемерида Moshier — суб-угловая секунда).
- **Геокодинг:** Локальная база городов (~150 000) и автоопределение часового пояса (`tz-lookup`).
- **Историческая точность времени:** Полная база IANA tzdb через `moment-timezone`.
- **Экспорт:** Скачивание карты в SVG, PDF (с поддержкой кириллицы) и JSON (с возможностью импорта).
- **Интерфейс:** iOS-стиль, адаптивность под телефоны, светлая и тёмная темы.

## 🛠 Стек технологий

- **Расчёт:** `swisseph-wasm` (Swiss Ephemeris в WebAssembly).
- **Визуализация:** `@astrodraw/astrochart` (SVG).
- **Время:** `moment-timezone`, `tz-lookup`.
- **PDF:** `jsPDF` + `svg2pdf.js`.
- **Города:** `cities.json` (загружается с CDN и кэшируется).
