# Астрология — карты, хорар, транзиты

Статический сайт для расчёта астрологических карт полностью в браузере. Никакого бэкенда — все вычисления выполняются на клиенте.

## Возможности

- **Натальная карта** с интерпретацией по системе Вронского
- **Транзиты** на любую дату
- **Соляр** — точный момент возвращения Солнца в натальную долготу
- **Синастрия** — би-колесо двух карт
- **Прогрессии** (вторичные: 1 день = 1 год)
- **Композит** — средняя карта пары
- **Символические дирекции** (1° = 1 год)
- **Хорар** — по правилам Лилли: кверент (1-й дом + Луна) и квезит (дом вопроса)
- **Транзиты на месяц** — список значимых транзитов внешних планет по домам
- Автогеокодинг городов (локальная база `cities.json` + `tz-lookup`)
- Полная историческая точность часовых поясов (`moment-timezone`)
- Экспорт **SVG**, **PDF** (с поддержкой кириллицы) и **JSON**
- Ссылка с параметрами карты для шаринга
- История последних 10 карт (`localStorage`)
- Светлая и тёмная темы, iOS-стиль на мобильных

## Стек

- **Расчёт:** `swisseph-wasm` (Swiss Ephemeris в WebAssembly, эфемерида Moshier)
- **Визуализация:** `@astrodraw/astrochart` (SVG)
- **Время:** `moment-timezone`, `tz-lookup`
- **PDF:** `jsPDF` + `svg2pdf.js`
- **Города:** `cities.json` (CDN)
