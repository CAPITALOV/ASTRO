# 🔮 Astro Site — профессиональная астрология в браузере

Полнофункциональное веб-приложение для астрологических расчётов с точностью NASA JPL. Работает полностью на клиенте — без сервера, без API-ключей, без регистрации.

**🌐 Демо:** [astro.sotis.org](https://astro.sotis.org/)
**📦 GitHub Pages:** [capitalov.github.io/astro](https://capitalov.github.io/astro/)

## ✨ Возможности

### 12 методов расчёта
Натальная · Транзиты · Соляр · Синастрия · Прогрессии · Композит · Дирекции · Хорар · Транзиты месяца · Профекции · Фирдарии · Карта Дэвисона

### Точность и настройки
- Swiss Ephemeris **JPL DE441**
- 6 систем домов
- Тропический и Сидерический зодиак
- Исторически точные часовые пояса
- Автогеокодинг 150 000 городов

### ИИ и экспорт
- 🤖 ИИ-разбор (промпт для ChatGPT)
- 📄 PDF с кириллицей
- 🖼 SVG-экспорт
- 📊 JSON-сохранение
- 📅 Гороскоп на сегодня

### Дизайн
- iOS-стиль
- Светлая/тёмная темы
- Кастомный акцентный цвет
- Полная адаптивность
